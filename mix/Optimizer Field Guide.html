Gradient Descent

梯度下降 Cauchy · 1847

Picture it形象理解

A blindfolded hiker feels which way the ground tilts and steps downhill.

蒙着眼下山：用脚感受地面往哪边倾斜，就朝下坡迈一步。

How it works原理

Move against the gradient. In a long, narrow valley it bounces between the walls, because the steepest direction rarely points at the bottom.

沿负梯度方向走。在狭长的山谷里，它会在两侧山壁之间来回反弹，因为最陡的方向很少直接指向谷底。

xk+1 = xk − α ∇f(xk)

Reach for it when适用场景

The baseline for everything else. Each step is cheap; progress is slow when the problem is badly conditioned.

所有方法的基准。每步很便宜；问题条件数差时进展很慢。

Stochastic Gradient Descent

随机梯度下降 SGD Robbins & Monro · 1951

Picture it形象理解

Instead of surveying the whole mountain, ask a few random passers-by which way is down. Each answer is noisy but right on average.

不去测量整座山，而是随机问几个路人哪边是下坡。每个回答都有噪声，但平均来说是对的。

How it works原理

Replace the full gradient with the gradient on a random mini-batch of data. The steps jitter, so the step size is shrunk over time.

用随机小批量数据上的梯度代替全量梯度。步子会抖，所以步长要随时间逐渐减小。

xk+1 = xk − αk g̃k,  𝔼[g̃k] = ∇f(xk)

Reach for it when适用场景

Training almost every neural network. One step costs a handful of examples instead of the whole dataset.

几乎所有神经网络的训练方式。一步只需要几个样本，而不是整个数据集。

Momentum & Nesterov

动量法与 Nesterov 加速 Polyak 1964 · Nesterov 1983

Picture it形象理解

A heavy ball rolling downhill keeps its speed across flat stretches. Nesterov's ball first looks at where it is about to land, then corrects.

滚下山的重球在平缓处也能保持速度。Nesterov 的球会先看一眼“将要落在哪里”，再修正方向。

How it works原理

Add a fraction β of the previous step to the current one. Nesterov evaluates the gradient at the look-ahead point, which gives the optimal O(1/k²) rate on smooth convex problems, versus O(1/k) for plain gradient descent.

把上一步的 β 倍加到当前步上。Nesterov 在“前瞻点”计算梯度，在光滑凸问题上达到最优的 O(1/k²) 收敛率；普通梯度下降只有 O(1/k)。

y = xk + β(xk − xk−1),  xk+1 = y − α∇f(y)

Reach for it when适用场景

Whenever gradient descent crawls along a long valley. SGD with momentum is the default in deep learning.

梯度下降在狭长山谷里爬得太慢时使用。带动量的 SGD 是深度学习的默认配置。

Proximal Gradient (ISTA / FISTA)

近端梯度法 ISTA 2004 · FISTA 2009

Picture it形象理解

Take an ordinary downhill step, then a tidy-up step that snaps small values to exactly zero.

先正常下坡一步，再做一步“修剪”：把很小的数直接剪成 0。

How it works原理

Split the objective into a smooth part plus a nonsmooth part such as the L1 norm. Take a gradient step on the smooth part, then apply the proximal operator of the other. For L1 that operator is soft-thresholding. FISTA adds Nesterov momentum.

把目标拆成光滑部分 + 非光滑部分（例如 L1 范数）。对光滑部分做梯度步，再对另一部分做近端算子。L1 的近端算子就是软阈值。FISTA 在此基础上加了 Nesterov 动量。

xk+1 = proxαg(xk − α∇f(xk))

Reach for it when适用场景

Lasso, sparse coding, compressed sensing, total-variation denoising: any objective with a kink.

Lasso、稀疏编码、压缩感知、全变分去噪：任何带“尖角”的目标函数。

Coordinate Descent

坐标下降 classic · revived for Lasso in the 2000s

Picture it形象理解

Tune an old radio with separate knobs: turn one knob to its best position, then the next.

像调老式收音机：先把一个旋钮拧到最好，再拧下一个。

How it works原理

Minimize along one coordinate at a time while the others stay frozen. The path is a staircase of axis-aligned moves.

固定其他变量，每次只沿一个坐标方向最小化。轨迹是一级级沿坐标轴的“楼梯”。

xi ← argmint f(x1, …, t, …, xn)

Reach for it when适用场景

When one-variable updates are cheap or have a closed form: Lasso solvers such as glmnet, SMO for support vector machines.

单变量更新很便宜或有闭式解时：glmnet 等 Lasso 求解器、支持向量机的 SMO 算法。

Frank–Wolfe

条件梯度法 Frank & Wolfe · 1956

Picture it形象理解

Inside a fenced field, find the corner that looks best right now and walk only part of the way toward it.

在围起来的场地里，找出此刻看起来最好的那个角，朝它走一段，但不走到底。

How it works原理

Linearize f, solve a linear problem over the feasible set (the answer is a vertex), and move a shrinking fraction γk = 2/(k+2) toward that vertex. No projection is ever needed.

把 f 线性化，在可行集上解一个线性子问题（答案是一个顶点），然后朝这个顶点走一小段，步长 γk = 2/(k+2)。全程不需要投影。

sk = argmins∈C ⟨∇f(xk), s⟩,  xk+1 = xk + γk(sk − xk)

Reach for it when适用场景

Feasible sets where projection is expensive but linear minimization is easy: the probability simplex, nuclear-norm balls, network flows.

投影很贵、但线性最小化很容易的可行集：概率单纯形、核范数球、网络流。

Newton's Method

牛顿法 Newton ~1669 · Raphson 1690

Picture it形象理解

Fit a bowl to the ground where you stand, then jump straight to the bottom of the bowl.

在脚下贴一个“碗”（二次近似），然后直接跳到碗底。

How it works原理

Use the gradient and the Hessian to build a quadratic model and jump to its minimum. Near the solution the number of correct digits roughly doubles every step (quadratic convergence).

用梯度和 Hessian 构造二次模型，直接跳到模型的最低点。接近解时，每一步正确的位数大约翻倍（二次收敛）。

xk+1 = xk − [∇²f(xk)]−1 ∇f(xk)

Reach for it when适用场景

Small and medium problems with a computable Hessian; the engine inside interior-point and SQP solvers. Each step costs O(n³).

中小规模、Hessian 可以计算的问题；内点法和 SQP 的内核。每步代价 O(n³)。

Conjugate Gradient

共轭梯度法 Hestenes & Stiefel · 1952

Picture it形象理解

Never undo earlier progress. Each new direction is chosen so it does not spoil the minimization already done along the old ones.

绝不走回头路：每个新方向都不会破坏之前方向上已经完成的最小化。

How it works原理

For a quadratic in n variables, conjugate directions reach the exact minimum in at most n steps (here n = 2). It only needs matrix-vector products, never the matrix itself.

对 n 维二次函数，共轭方向最多 n 步到达精确最小点（这里 n = 2）。只需要矩阵-向量乘积，不需要显式存储矩阵。

dk+1 = −gk+1 + βkdk,  diTA dj = 0 (i ≠ j)

Reach for it when适用场景

Huge sparse linear systems Ax = b, and the inner solver of truncated-Newton methods.

超大稀疏线性方程组 Ax = b，以及截断牛顿法的内层求解器。

BFGS / L-BFGS

拟牛顿法 BFGS 1970 · L-BFGS 1989

Picture it形象理解

Learn the shape of the terrain from your own footprints: how the slope changed after each step reveals the curvature.

从自己的脚印里学习地形：每走一步，坡度的变化就透露出曲率。

How it works原理

Build an approximation of the inverse Hessian from step pairs s = Δx and y = Δ∇f. L-BFGS keeps only the last m pairs (typically 5 to 20), so memory is O(mn).

用步长对 s = Δx、y = Δ∇f 逐步构造逆 Hessian 的近似。L-BFGS 只保存最近 m 对（通常 5 到 20），内存只需 O(mn)。

Hk+1 = (I − ρsyT) Hk (I − ρysT) + ρssT,  ρ = 1/(yTs)

Reach for it when适用场景

The default for smooth unconstrained problems when you have gradients but no Hessian, even with millions of variables (L-BFGS).

有梯度、没有 Hessian 的光滑无约束问题的首选；变量上百万也能用（L-BFGS）。

Gauss–Newton & Levenberg–Marquardt

高斯-牛顿与 LM 算法 Gauss 1809 · Levenberg 1944 · Marquardt 1963

Picture it形象理解

Fitting a curve to data points. Levenberg–Marquardt has a dial between bold (Gauss–Newton) and careful (gradient descent).

把曲线拟合到数据点上。LM 有一个旋钮，在“大胆”（高斯-牛顿）和“谨慎”（梯度下降）之间调节。

How it works原理

For least squares ½‖r(x)‖², approximate the Hessian by JᵀJ using only first derivatives of the residuals. LM adds a damping term λ: small λ behaves like Gauss–Newton, large λ like a short gradient step.

对最小二乘 ½‖r(x)‖²，只用残差的一阶导数，以 JᵀJ 近似 Hessian。LM 再加阻尼 λ：λ 小时像高斯-牛顿，λ 大时像一小步梯度下降。

(JTJ + λI) δ = −JTr

Reach for it when适用场景

Curve fitting, camera calibration, bundle adjustment, SLAM back-ends such as Ceres and g2o.

曲线拟合、相机标定、光束法平差（BA）、Ceres、g2o 等 SLAM 后端。

Line Search vs Trust Region

线搜索与信赖域 Armijo 1966 · Wolfe 1969 · Powell 1970

Picture it形象理解

Two safety rules for any step. Line search: choose a direction, then decide how far. Trust region: decide how far you trust your map, then choose the best step inside that circle.

迈步的两种安全规则。线搜索：先定方向，再定走多远。信赖域：先定“地图可信的半径”，再在圈内找最好的一步。

How it works原理

Backtracking tries α = 1, ½, ¼, … until the decrease is large enough (the Armijo condition). A trust region grows when the model predicted well and shrinks when it did not.

回溯线搜索依次尝试 α = 1, ½, ¼, …，直到下降量足够大（Armijo 条件）。信赖域在模型预测准确时扩大半径，不准时缩小。

f(x + αd) ≤ f(x) + c·α·∇f(x)Td

Reach for it when适用场景

Not algorithms on their own, but the wrappers that make Newton and quasi-Newton methods converge from far away.

它们不是独立的算法，而是让牛顿法、拟牛顿法从远处也能收敛的“外壳”。

Simplex Method

单纯形法 Dantzig · 1947

Picture it形象理解

The feasible region of a linear program is a gem with flat faces. The best point is always at a corner, so walk along the edges from corner to corner, always improving.

线性规划的可行域像一颗有平面切面的宝石。最优解一定在某个顶点上，所以沿着棱从一个顶点走到相邻顶点，每次都更好。

How it works原理

Move between adjacent vertices while the objective improves; stop when no neighbor is better. Exponential in the worst case (Klee–Minty, 1972) yet very fast in practice.

沿相邻顶点移动，只要目标在改善；没有更好的邻居时停止。最坏情况是指数时间（Klee–Minty, 1972），实际中却非常快。

max cTx  s.t.  Ax ≤ b,  x ≥ 0

Reach for it when适用场景

Linear programming. Still a core engine in commercial solvers, and excellent for warm starts inside branch-and-bound.

线性规划。至今仍是商业求解器的核心引擎，在分支定界里热启动尤其好用。

Interior-Point Methods

内点法 Karmarkar 1984 · primal-dual late 1980s

Picture it形象理解

Instead of crawling along the walls, cut through the middle. A force field keeps you away from the walls; weaken it step by step and the path slides toward the best corner.

不沿着墙爬，而是从中间穿过去。一个“力场”让你远离墙壁；逐步减弱力场，路径就滑向最优顶点。

How it works原理

Replace the constraints with a log-barrier, minimize −t·cᵀx − Σ log(bᵢ − aᵢᵀx) with Newton's method, and increase t. The minimizers trace the central path. Polynomial time, usually 20 to 50 Newton steps whatever the size.

用对数障碍代替约束，用牛顿法最小化 −t·cᵀx − Σ log(bᵢ − aᵢᵀx)，并不断增大 t。这些最小点连成“中心路径”。多项式时间，通常 20 到 50 次牛顿迭代，几乎与规模无关。

x*(t) = argmin −t·cTx − Σi log(bi − aiTx)

Reach for it when适用场景

Large LP, QP, SOCP and SDP problems (MOSEK, the barrier option in Gurobi), and IPOPT for nonlinear programs.

大规模 LP、QP、SOCP、SDP（MOSEK、Gurobi 的 barrier 算法），非线性规划用 IPOPT。

Penalty & Barrier Functions

罚函数与障碍函数 Courant 1943 · Fiacco & McCormick 1968

Picture it形象理解

Two ways to keep someone inside a fence. Penalty: trespassing is allowed but the fine keeps growing. Barrier: an electric fence that hurts more the closer you get, so you never cross.

让人待在围栏里的两种办法。罚函数：允许越界，但罚款越来越重。障碍函数：电网，越靠近越疼，所以永远不会越过。

How it works原理

As μ grows, penalty minimizers approach the boundary from outside (infeasible). As t grows, barrier minimizers approach it from inside (always feasible). Both become ill-conditioned at the extreme.

μ 增大时，罚函数的最小点从外侧（不可行）逼近边界；t 增大时，障碍函数的最小点从内侧（始终可行）逼近。两者在极端参数下都会变得病态。

f(x) + μ·max(0, g(x))2   vs   f(x) − (1/t)·log(−g(x))

Reach for it when适用场景

Easy to implement. The barrier is the seed of interior-point methods; the penalty is the seed of the augmented Lagrangian.

实现简单。障碍函数是内点法的种子，罚函数是增广拉格朗日法的种子。

Augmented Lagrangian

增广拉格朗日法（乘子法） Hestenes, Powell · 1969

Picture it形象理解

A fine alone has to be enormous to work. Add a price that is renegotiated each round: if people keep crossing the line the price rises, and a moderate fine becomes enough.

只靠罚款，罚款得大得离谱才管用。再加一个每轮重新谈判的“价格”（乘子）：总有人越线，价格就上调，于是适中的罚款就够了。

How it works原理

Minimize f + λh + (μ/2)h², then update the multiplier λ ← λ + μh. It converges to the exact constrained solution with a fixed, moderate μ.

最小化 f + λh + (μ/2)h²，然后更新乘子 λ ← λ + μh。用固定、适中的 μ 就能收敛到精确的约束解。

Lμ(x, λ) = f(x) + λTh(x) + (μ/2)‖h(x)‖2

Reach for it when适用场景

Equality-constrained problems; the parent of ADMM; used in LANCELOT and in trajectory optimizers such as ALTRO.

等式约束问题；ADMM 的前身；LANCELOT 以及 ALTRO 等轨迹优化器都用它。

ADMM

交替方向乘子法 Glowinski–Marrocco 1975 · Gabay–Mercier 1976

Picture it形象理解

Two teams each solve their half of the problem, a mediator charges them for any disagreement, and they go again.

两个团队各自解决问题的一半，协调员对两者的分歧“收费”，然后再来一轮。

How it works原理

Write the problem as min f(x) + g(z) subject to x = z. Alternate: minimize over x, minimize over z, then raise the price λ of disagreement. Each piece is often easy or closed-form.

把问题写成 min f(x) + g(z)，s.t. x = z。交替进行：对 x 最小化，对 z 最小化，再调高分歧的“价格” λ。每一块往往都很简单，甚至有闭式解。

x ← argmin Lρ(x, z, λ);  z ← argmin Lρ(x, z, λ);  λ ← λ + ρ(x − z)

Reach for it when适用场景

Large-scale and distributed convex problems, Lasso, consensus optimization. OSQP, a widely used QP solver in MPC, is built on ADMM. Boyd et al.'s 2011 review made it popular.

大规模、分布式凸问题，Lasso，一致性优化。MPC 中广泛使用的 QP 求解器 OSQP 就基于 ADMM。Boyd 等人 2011 年的综述让它流行起来。

Sequential Quadratic Programming

序列二次规划 SQP Wilson 1963 · Han 1977 · Powell 1978

Picture it形象理解

The fence is curved and the ground is bumpy. At every step, pretend the fence is straight and the ground is a bowl, solve that easy problem, and take the step.

围栏是弯的，地面也坑坑洼洼。每一步都假装围栏是直线、地面是一个碗，解这个简单问题，然后迈出这一步。

How it works原理

Linearize the constraints and use a quadratic model of the Lagrangian; the resulting QP gives the step. It is Newton's method applied to the KKT conditions, so convergence is fast near the solution.

把约束线性化，用拉格朗日函数的二次模型，解出的 QP 给出步长。它本质上是对 KKT 条件用牛顿法，所以在解附近收敛很快。

mind ∇fTd + ½dT∇²L d  s.t.  h + ∇hTd = 0

Reach for it when适用场景

Nonlinear constrained problems with expensive functions: trajectory optimization, aerospace design (SNOPT), robot motion (acados).

函数评估昂贵的非线性约束问题：轨迹优化、航空航天设计（SNOPT）、机器人运动（acados）。

Dynamic Programming

动态规划 Bellman · 1950s

Picture it形象理解

Plan a trip backward from the destination. Once you know the cheapest cost from every square to the goal, the best route is obvious.

从终点倒着规划：一旦知道每个格子到终点的最低成本，最优路线就一目了然。

How it works原理

Break the problem into overlapping subproblems and solve each one once. The Bellman equation: value here = cost here + the best value among the next moves.

把问题拆成相互重叠的子问题，每个只解一次。Bellman 方程：此处的价值 = 此处的成本 + 下一步中最好的价值。

V(s) = c(s) + mins′ ∈ next(s) V(s′)

Reach for it when适用场景

Shortest paths, sequence alignment, knapsack, optimal control. It is also the foundation of reinforcement learning.

最短路径、序列比对、背包问题、最优控制，也是强化学习的基础。

Branch and Bound

分支定界法 Land & Doig · 1960

Picture it形象理解

Explore a tree of yes/no choices, but cut off any branch whose best possible outcome is already worse than a solution you hold.

在“是/否”决策树上探索；只要某个分支能达到的最好结果已经不如手上的解，就把它剪掉。

How it works原理

Solve the LP relaxation for an optimistic bound. If the answer is fractional, branch into x ≤ ⌊v⌋ and x ≥ ⌈v⌉. Discard nodes that are infeasible or whose bound cannot beat the incumbent.

解 LP 松弛，得到乐观的上界。若解是分数，就分支为 x ≤ ⌊v⌋ 和 x ≥ ⌈v⌉。不可行、或上界不可能超过当前最优解的节点直接丢弃。

max 5x1 + 4x2  s.t.  6x1 + 4x2 ≤ 24,  x1 + 2x2 ≤ 6,  x ∈ ℤ2≥0

Reach for it when适用场景

Integer and mixed-integer programming: scheduling, routing, facility location. Gurobi, CPLEX and SCIP all branch.

整数与混合整数规划：排班、路径规划、选址。Gurobi、CPLEX、SCIP 都在做分支。

Cutting Planes

割平面法 Gomory · 1958

Picture it形象理解

The LP answer sits on a fractional corner. Slice that corner off with a cut that keeps every integer point, then solve again.

LP 的解落在一个分数顶点上。用一刀切掉这个角，同时保留所有整数点，然后重新求解。

How it works原理

Add valid inequalities that separate the fractional LP solution from the convex hull of the integer points. Modern solvers combine cuts with branching (branch-and-cut).

添加有效不等式，把分数 LP 解与整数点的凸包分开。现代求解器把割平面和分支结合起来（branch-and-cut）。

max y  s.t.  −x + y ≤ 1,  3x + 2y ≤ 12,  2x + 3y ≤ 12,  x, y ∈ ℤ≥0

Reach for it when适用场景

Every serious MIP solver. The same idea drives Benders decomposition.

所有严肃的 MIP 求解器都在用。Benders 分解背后也是同样的思想。

Nelder–Mead

Nelder–Mead 下山单纯形法 Nelder & Mead · 1965

Picture it形象理解

A triangle tumbles downhill: it flips its worst corner over the opposite side, stretches when that works, and shrinks when it does not.

一个三角形翻滚着下山：把最差的顶点翻到对面去，有效就拉伸，无效就收缩。

How it works原理

Keep n + 1 points (a simplex). Each step reflects, expands, contracts or shrinks using function values only. No gradients and, in general, no convergence guarantee, but robust on small problems.

维护 n + 1 个点（一个单纯形）。每一步只用函数值做反射、扩张、收缩或整体缩小。不需要梯度，一般情况下也没有收敛保证，但对小问题很稳。

xr = x̄ + (x̄ − xworst)

Reach for it when适用场景

Low-dimensional (up to about 10 variables), noisy or non-differentiable tuning; scipy's fmin. It has nothing to do with Dantzig's simplex method.

低维（约 10 个变量以内）、有噪声或不可导的调参；scipy 的 fmin。它和 Dantzig 的单纯形法没有关系。

Simulated Annealing

模拟退火 Kirkpatrick, Gelatt & Vecchi · 1983

Picture it形象理解

Like cooling metal: shake hard while it is hot so you can escape shallow pits, then cool slowly and settle in the deepest one.

像金属退火：高温时剧烈抖动，能跳出浅坑；然后慢慢冷却，最后停在最深的坑里。

How it works原理

Propose a random move. Always accept it if it is better; accept a worse move with probability e−Δ/T. Lower the temperature T over time.

随机提出一个移动。更好就接受；更差时以概率 e−Δ/T 接受。随时间降低温度 T。

P(accept) = min(1, e−Δf/T)

Reach for it when适用场景

Combinatorial problems with many local optima: chip placement, scheduling, the traveling salesman problem.

局部最优很多的组合问题：芯片布局、排程、旅行商问题。

Genetic Algorithms

遗传算法 Holland · 1975

Picture it形象理解

Survival of the fittest for solutions: keep the good ones, mix their traits, add random mutations, and repeat for generations.

解的“适者生存”：保留好的解，混合它们的特征，加一点随机突变，一代代重复。

How it works原理

Maintain a population. Select parents by fitness, recombine them (crossover), mutate, and replace. Works on any encoding: bit strings, permutations, even programs.

维护一个种群。按适应度选择父代，交叉重组，突变，再替换。适用于任何编码：比特串、排列，甚至程序。

select → crossover → mutate → replace

Reach for it when适用场景

Messy design spaces with mixed discrete choices: neural architecture search, the evolved antenna on NASA's ST5 satellites.

混杂离散选择的复杂设计空间：神经架构搜索，NASA ST5 卫星上进化出来的天线。

CMA-ES

协方差矩阵自适应进化策略 Hansen & Ostermeier · 1996 / 2001

Picture it形象理解

A cloud of guesses that learns the shape of the valley: it stretches along directions that keep paying off and drifts toward the good region.

一团会学习山谷形状的“猜测云”：沿着持续带来收益的方向拉长，并漂向好的区域。

How it works原理

Sample from a Gaussian N(m, σ²C), rank the samples, move the mean toward the best ones, and update the covariance C from successful steps. It effectively learns a second-order model without derivatives.

从高斯分布 N(m, σ²C) 采样，对样本排序，把均值移向最好的样本，并用成功的步更新协方差 C。相当于不用导数就学到了一个二阶模型。

xi ~ m + σ·𝒩(0, C)

Reach for it when适用场景

Hard continuous black-box problems up to roughly 100 dimensions; robot gait and controller tuning.

困难的连续黑箱问题（约 100 维以内）；机器人步态与控制器调参。

Bayesian Optimization

贝叶斯优化 Mockus 1970s · Jones et al. (EGO) 1998

Picture it形象理解

When every taste test is expensive, keep a map of what you believe and how unsure you are, then taste next where the map says it is promising or unknown.

每次试吃都很贵时，就维护一张“信念地图”（包括不确定性），下一口选在地图显示“有希望”或“还不清楚”的地方。

How it works原理

Fit a Gaussian process to the evaluations so far. An acquisition function, here Expected Improvement, trades off exploitation against exploration and picks the next point.

用高斯过程拟合已有的评估结果。采集函数（这里是期望改进 EI）在“利用”和“探索”之间权衡，选出下一个点。

xnext = argmax EI(x),  EI(x) = 𝔼[max(0, fbest − f(x))]

Reach for it when适用场景

Very expensive evaluations with few variables: hyperparameter tuning, experiment design, sim-to-real parameter tuning.

评估极其昂贵、变量不多：超参数调优、实验设计、仿真到真机的参数调节。

Adam

Adam 优化器 Kingma & Ba · 2014

Picture it形象理解

Give every coordinate its own stride: long steps where the slope is consistently gentle, short steps where it is steep or noisy.

每个坐标有自己的步幅：坡度一直平缓的方向迈大步，陡峭或嘈杂的方向迈小步。

How it works原理

Momentum on the gradient (first moment) divided by a running root-mean-square of the gradient (second moment), with bias correction. The lineage is SGD → momentum → Adam.

梯度的动量（一阶矩）除以梯度平方的滑动均方根（二阶矩），再做偏差修正。演化路线是 SGD → 动量 → Adam。

xk+1 = xk − α·m̂k / (√v̂k + ε)

Reach for it when适用场景

The workhorse of deep learning. Its theory is much thinner than the classics: Reddi, Kale & Kumar (2018) built a simple convex problem on which it fails to converge.

深度学习的主力。但理论远不如经典方法扎实：Reddi、Kale 与 Kumar（2018）构造了一个简单的凸问题，Adam 在上面不收敛。

DDP / iLQR

微分动态规划 / 迭代 LQR Mayne 1966 · Jacobson & Mayne 1970 · Li & Todorov 2004

Picture it形象理解

Start with a rough trajectory, then repeatedly bend the whole path using a local quadratic model at every time step.

从一条粗糙的轨迹出发，然后在每个时间步用局部二次模型，反复修整整条路径。

How it works原理

Backward pass: dynamic programming on a quadratic approximation of the cost and a linear (iLQR) or quadratic (DDP) approximation of the dynamics gives a feedback gain for every step. Forward pass: roll out the improved controls.

反向传递：对代价做二次近似、对动力学做线性（iLQR）或二次（DDP）近似，用动态规划算出每一步的反馈增益。前向传递：用改进后的控制量重新推演。

δut = kt + Kt·δxt

Reach for it when适用场景

Trajectory optimization for robot arms, legged robots and drones. As a bonus it returns a local feedback controller.

机械臂、足式机器人、无人机的轨迹优化。附带得到一个局部反馈控制器。

Model Predictive Control

模型预测控制 MPC industrial use from the late 1970s

Picture it形象理解

Drive by looking a few seconds ahead: plan the next few seconds, carry out only the first move, then re-plan from where you actually are.

开车时只看前方几秒：规划接下来几秒，只执行第一步，然后从实际位置重新规划。

How it works原理

At every control tick, solve a finite-horizon optimal control problem (often a QP with OSQP, or an NLP with SQP or interior point), apply the first control, and slide the window.

每个控制周期都求解一个有限时域的最优控制问题（常用 OSQP 解 QP，或用 SQP/内点法解 NLP），只执行第一个控制量，然后窗口前移。

minu0…N−1 Σt ℓ(xt, ut) + ℓN(xN)  s.t.  xt+1 = f(xt, ut)

Reach for it when适用场景

Process control, autonomous driving, legged locomotion. This is where SQP, interior point and ADMM meet real robots.

过程控制、自动驾驶、足式机器人运动。SQP、内点法、ADMM 就是在这里和真实机器人相遇的。
