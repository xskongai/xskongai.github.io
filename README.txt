XSKONGAI — MONOCHROME HOMEPAGE

Files:
  index.html  Homepage content and semantic structure
  style.css   Fully grayscale design, desktop and mobile layouts

To publish to https://xskongai.github.io/:
1. Open your repository: https://github.com/xskongai/xskongai.github.io
2. Back up your current index.html and style.css.
3. Replace both files with these two new files in the repository root.
4. Commit the changes to the branch used by GitHub Pages.

Local preview:
  Open index.html directly in a browser, or run:
  python3 -m http.server 8000
  then visit http://localhost:8000

Notes:
- Entire site uses neutral grayscale colors (R=G=B).
- No framework, external fonts, or JS dependencies.
- The old LinkedIn link pointed to the LinkedIn homepage, and the email was
  a placeholder. Both are intentionally excluded from visible contact links.
  There are commented examples in index.html if you want to add real links.
- PAIFAR's public GitHub repository is linked; no project links were invented.
